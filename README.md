# Flick注音輸入法
**Flick注音輸入法** 是一個 100% 使用 **Kotlin** 與 **Jetpack Compose** 開發的現代化Android輸入法。

核心主打為 **Flick注音** 輸入模式，旨在透過 flick 的方式拖曳按鍵，讓小螢幕能更好打字，不再昂鞥而。

本專案為[Flick行列輸入法](https://github.com/crest247/FlickArrayKeyboard)之延伸專案。
